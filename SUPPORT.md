# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Before
opening an issue, search existing issues and test against the latest version on
the default branch.

Include:

- operating system and Python version
- LinguaMCP version or commit
- MCP client and transport mode
- minimal reproduction steps
- expected and actual behavior
- relevant sanitized error output

Never post learner data, passwords, bearer tokens, OAuth codes, environment
variables, audit logs containing sensitive metadata, or public tunnel secrets.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue. General language-learning advice and client-specific account
support are outside this project's support scope.
